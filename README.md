#### 🔐 [HashCave](https://github.com/krishanu-d/HashCave) — Zero-Knowledge Password Manager
> Actively in development

A local-first, encrypted password manager in React Native (no Expo) with zero server-side secrets.

**Highlights:**
- AES-256-GCM encryption with PBKDF2 key derivation (200k iterations)
- Salt stored in Android Keychain + Google Drive `appDataFolder`
- Custom TurboModules in Kotlin: `HCCryptoModule`, `HCKeychainModule`, `HCBiometricModule`, `HCClipboardModule`
- Google Drive REST API sync with timestamp-based conflict resolution
- RevenueCat subscription gating (free: 25 credentials · Pro: unlimited + TOTP + password health)
